# ⚡ Offline Media Toolkit - Browser Extension Guide

Run all VideoKit tools directly in your browser with **100% offline support** and **zero internet required**.

---

## 🚀 How to Install in 3 Easy Steps (Developer Mode)

### Step 1: Open Extensions in your Browser
- In **Google Chrome** or **Brave**: Navigate to `chrome://extensions`
- In **Microsoft Edge**: Navigate to `edge://extensions`
- In **Opera**: Navigate to `opera://extensions`

### Step 2: Enable "Developer Mode"
- Locate the **"Developer mode"** toggle switch in the top-right corner of the Extensions page.
- Turn the toggle **ON**.

### Step 3: Load Unpacked Extension
- Click the **"Load unpacked"** button in the top-left toolbar.
- Select this `extension` folder (`vite/extension`).
- Done! The **Offline Media Toolkit** icon will appear in your browser extensions menu!
